# تطبيق إرسال رسائل واتساب جماعية

تطبيق ويب بسيط وسهل الاستخدام لإرسال رسائل واتساب لعدة أشخاص في نفس الوقت.

## الميزات

✨ **إضافة جهات اتصال** - أضف أسماء وأرقام جوال بسهولة
📱 **اختيار نوع الواتساب** - اختر بين واتساب عادي أو واتساب أعمال
💬 **إرسال رسائل مخصصة** - اكتب الرسالة التي تريد إرسالها
🎨 **تصميم حديث** - واجهة داكنة وسهلة الاستخدام
⚡ **بدون تعقيدات** - كل شيء في صفحة واحدة
📝 **HTML/CSS/JS عادي** - سهل التعديل في أي محرر نصوص

## كيفية الاستخدام

1. **أضف جهات اتصال:**
   - أدخل اسم الشخص
   - أدخل رقم جواله (بصيغة 05xxxxxxxx)
   - اضغط زر "إضافة"

2. **اكتب الرسالة:**
   - اكتب الرسالة التي تريد إرسالها في حقل الرسالة
   - اختر نوع الواتساب (عادي أو أعمال)

3. **أرسل الرسالة:**
   - اضغط على زر الإرسال (الأخضر) بجانب جهة الاتصال
   - سيفتح واتساب مع الرسالة معدة وجاهزة للإرسال
   - اضغط زر الإرسال في واتساب لإرسال الرسالة

## التشغيل

ببساطة افتح ملف `index.html` في متصفحك!

أو استخدم أي خادم محلي:
```bash
# Python 3
python -m http.server 8000

# Node.js (إذا كان مثبتاً)
npx http-server
```

ثم افتح `http://localhost:8000` في متصفحك.

## التعديل

يمكنك تعديل الملفات مباشرة:
- **index.html** - لتغيير الهيكل والعناصر
- **style.css** - لتغيير الألوان والتصميم
- **script.js** - لتغيير الوظائف والسلوك

## المتطلبات

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- اتصال إنترنت
- تطبيق واتساب مثبت أو واتساب ويب
